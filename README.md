# 詠葉的婚禮

這是 **黃律詠與葉藝慧** 的婚禮專案資料庫，用來集中保存與整理婚禮相關文件、設計素材及流程紀錄。

## 婚禮資訊

- 日期：2026 年 6 月 20 日
- 地點：德光長老教會
- 形式：結婚感恩禮拜

## 專案用途

- 保存婚禮流程與程序單
- 彙整設計稿、插畫與印刷版本
- 管理文字、音樂、影片及相關素材
- 記錄工作分配與修改歷程

## 主要內容

- 婚禮程序單
- 封面及內頁設計
- 婚禮流程與人員名單
- 音樂、影片與其他婚禮素材

## 網站部署

`/Memories` 是前端單頁應用程式路由。正式環境必須將 `/Memories` 與
`/Memories/` 的直接請求 rewrite 到網站的 `index.html`，否則使用者重新整理或
直接開啟該網址時可能收到 404。這項 rewrite 由部署平台設定，不由前端路由處理。
